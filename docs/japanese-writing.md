# japanese-writing

AI が書く日本語は、箇条書きと「**見出し**：説明」の形が多く、文と文をつなぐ接続詞が少なく、話し言葉と書き言葉が混ざります。japanese-writing は、読み手と場面（社内か社外か、メールかチャットか）から文体・順番・長さを決める手順と、こうした形を避ける書き方をエージェントに渡します。

入れる前と後で、変更の記録から作業報告を書かせた例です。

```
入れる前：
- **ブラウザ操作（#104、11/9）**：Web ページを開く・読む・入力する作業の手順。手段の選び方と、ログインや取り消せない操作の扱いを決めた。

入れた後：
11月9日に、Web ブラウザを操作する手順を追加しました。ページを開く手段を選ぶ順序と、ログインや取り消せない操作の扱いを定めています。
```

## Skill あり・なしで比べる

同じ依頼を、同じモデル（Claude Sonnet）に、Skill を読ませる場合と読ませない場合で1回ずつ書かせました（2026年11月14日）。書き手は、会話の経緯や指示ファイルを持たない新しいサブエージェントです。Skill ありでは、書く前に SKILL.md と、Skill に含まれる業務の文書の資料（references/business.md）を読ませました。依頼は次の3つです。

| 依頼 | Skill ありで変わった所 |
|---|---|
| 変更の記録から、チーム向けの週報を Slack に書く | 冒頭に今週の結論を2文で置いた。日付に曜日を添えた。相談したいことを、来週の予定の文の中で目的とともに書いた。一方で、「調査中」の区分が消え、調査だけの件が完了の件と同じ並びに入った（悪くなった点） |
| 取引先に、納品日を延ばしたいとメールで頼む | 件名に用件と結論（12月5日に延ばしたい）を入れた。日付に曜日を添えた（暦で確かめると正しかった）。試用版を先に渡す理由（意見を反映できる）を足した |
| 公開する CLI の README の冒頭を書く | 「安心して試せます」「ダウンロードしてすぐ使えます」のような売り込みの言い方が消えた。金額の列を数字にすると何ができるか（数値として読み込める）を書いた |

同梱の検査スクリプトの指摘の数は、どちらも0〜1件で差が出ませんでした。この程度の長さの文なら、今のモデルは Skill が無くても、検査で拾える形（くだけた言葉、長すぎる文など）をあまり書きません。Skill の有無で、何をどの順で書くかが変わりました。

この3つの依頼では Skill によって結論や件名が先に来て、日付に曜日が付き、売り込みの言葉が消えました。1回ずつの比べなので、同じ差がいつも出るとは限りません。週報の依頼は、SKILL.md の中の例（変更の記録から書く作業報告）と似ています。README の依頼では、Skill なしの文だけが「「1,200円」は 1200 になります」という具体例を書いていて、その点は Skill ありの文より分かりやすくなっていました。

csv-tidy は、CSV ファイルを分析や取り込みの前に整えるための、コマンドラインの道具です。文字化けや表記のゆれを、1回のコマンドでまとめて片づけます。文字コードが Shift_JIS のファイルも、BOM 付きや BOM なしの UTF-8 のファイルも、自動で見分けて UTF-8 にそろえます。列の名前の前後にある空白を取り除き、全角の英数字も直します。金額の列は、--money に列名を渡すと、カンマと「円」を外して数字だけにします。たとえば「1,200円」は 1200 になります。

元のファイルは書き換えず、結果は別のファイルに出すので、安心して試せます。Windows・Mac・Linux 向けの実行ファイルをそれぞれ1つずつ配っています。Python などを入れる必要はなく、ダウンロードしてすぐ使えます。

Skill あり：

```
csv-tidy は、日本語の CSV を扱いやすい形に整えるコマンドラインツールです。文字コードが Shift_JIS か、BOM 付きまたは BOM なしの UTF-8 かを自動で判別して、すべて UTF-8 にそろえます。文字コードを指定する必要はありません。

あわせて、列名の前後の空白を取り除き、全角の英数字を半角にします。金額の列は、--money に列名を指定すると、カンマと「円」を外して数字のみの値にします。そのため、後続の処理で数値として読み込めます。

元のファイルは書き換えず、結果は別のファイルに出力します。実行ファイルは Windows、Mac、Linux 向けに1つずつ配布しており、Python などのインストールは不要です。

使用例は次のとおりです。売上.csv の「金額」列を数字にして、売上-整形.csv に出力します。

csv-tidy 売上.csv --money 金額 --out 売上-整形.csv
```

</details>


## 使い方

日本語の文章を書く依頼をすると、エージェントが Skill の説明を見て自動で読み込みます。読み込まれない場合は、依頼に「japanese-writing の Skill を使って」と書きます。

同梱の検査スクリプト `scripts/check.mjs` は、書いた文章のファイルを読み、確認したほうがよい箇所を行番号付きで一覧にします。ファイルは書き換えません。エージェントは Skill の手順に従って実行します。自分で実行する場合は次のとおりです。

```
node skills/japanese-writing/scripts/check.mjs 文章.md
```
