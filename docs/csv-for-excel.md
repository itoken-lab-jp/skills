# csv-for-excel

AI エージェント（Claude Code や Codex のように、ファイルを読み書きして作業を進める AI）に CSV を作らせて、人が Excel で開いて使うと、値が変わってしまうことがあります。Excel は CSV をダブルクリックで開くと、セルごとに中身を見て数値や日付に読み替えるからです。顧客コードの `000123` は `123` に、番地の `1-2` は `1月2日` に、20桁の伝票番号は `2.03E+19` になります。CSV のファイルをメモ帳などで見ると正しいので、AI が作ったあとに中身を読んで確かめても、誤りは見えません。開いた人がそのまま上書き保存すると、元の値は戻りません。

csv-for-excel は、Excel が書き換える値の形を AI に見分けさせ、書き換えられない形で CSV を書かせ、Excel で開いて確かめさせる、AI が読む手順書（Skill）です。顧客の一覧や取引の明細のような CSV を AI に作らせて、ほかの人に Excel で使ってもらう人に向いています。

## 使い方

Claude Code・Codex など、Skill の共通の形式（[Agent Skills](https://agentskills.io/specification)。フォルダーに手順書の `SKILL.md` を置く形）を読むエージェントで使えます。入れ方は [README](../README.md) のコマンド（`npx skills add itoken-lab-jp/skills -g --skill csv-for-excel`）です。入れておくと、エージェントは `SKILL.md` の先頭にある説明文（どんなときに読むか）を見て、次のような頼みのときに自分で読み込みます。

- 「顧客.json を CSV にして。営業の人たちが Excel で開いて使います」
- 「取引明細を経理の人に渡すので、CSV にして」
- 「CSV を Excel で開いたら、住所の番地が日付になった。直して」

人が開くのか分からない頼み（「売上の合計を CSV に出して」のような、集計の結果を書くだけのもの）と、別のシステムに取り込ませる CSV では読み込みません。取り込ませる CSV に Excel 向けの書き方を入れると、取り込んだ先に `="` の字が残るためです。

## Excel に書き換えさせない書き方

Skill は、変わる値を `="1-2"` の形で書かせます。Excel はこれを「`1-2` という文字を表示する式」として読むので、日付にも数値にもしません。ただし、メモ帳やほかのシステムでは `="1-2"` のまま見えます。そのため、AI は、どの列をこの形にしたかを返事に書きます。.xlsx でもよいと頼めば、セルの書式を文字列にした .xlsx で作らせることもできます。

文字化けは、ファイルの先頭に「UTF-8 で書いた」という印（BOM）を付けて防ぎます。

## 試した結果

2026-11-16 に、作者の日本語の Windows 11（Microsoft 365 の Excel が入っている）で、Claude Code に頼みました（モデルは Sonnet）。1つの環境、1つのモデルでの試しです。Mac の Excel、古い版の Excel、ほかの AI では試していません。AI が作った CSV は、作者が Excel で開き、セルの表示が元の値と同じかを確かめました。

まず Skill なしで、日本語の仕事で AI がつまずきそうな 11 の場面を、場面ごとに 3 回頼みました。Excel の CSV のほかは、日本語のファイル名、文字コード、会計の決まり（消費税の端数、和暦の年度）などで、AI が外しやすいと言われる所です。外したのは、Excel で開く CSV だけでした。

- 「営業の人たちが Excel で開いて使います」と頼んだ顧客の一覧：3 回とも、文字化けと先頭の0には対処しました。番地の列の `1-2`・`3-15` は 3 回とも見落とし、Excel で開くと `1月2日`・`3月15日` になりました。
- 「経理の人に渡す」とだけ頼んだ取引の明細（20桁の伝票番号、`1E5` の形の品番、`1.10` の形の規格、`2-3` の形の部屋番号）：3 回のうち 1 回は、どの列も対処せず、Excel で開くと全部が変わりました。

次に Skill ありで、同じ頼みを 3 回ずつ頼みました。

| 頼み | Skill なし | Skill あり |
|---|---|---|
| 顧客の一覧（Excel で開くと書いた） | 3 回とも番地が日付になる | 3 回とも全部の値がそのまま |
| 取引の明細（経理に渡すとだけ書いた） | 3 回中 1 回、全部の列が変わる | 3 回とも全部の値がそのまま |
| 基幹システムに取り込む CSV | — | 2 回とも Skill は読み込まれず、値をそのまま書いた |
| 店舗・月ごとの売上の合計を CSV に出す | 3 回とも値をそのまま | 2 回とも Skill は読み込まれず、値をそのまま |

下の2行は、Excel 向けの書き方が要らない頼みで、Skill が余計なことをしないかを見るためのものです。最初に書いた説明文では、合計の CSV の頼みでも Skill が読まれ、Excel 向けの書き方が入りました。説明文を「Excel や渡す相手が出てくる頼み」に絞り、表はその後の版で試した結果です。

## SKILL.md に書いてあること

AI が読むファイルです。使うだけなら読まなくてかまいません。どう動くかを確かめたいときは [SKILL.md](../skills/csv-for-excel/SKILL.md) を開いてください。

- Excel で開いたときに変わる値の形の表です。先頭の0、`1-2` や `1-2-3`（全角のハイフンも）、`3/15`、`2026-11`、15桁を超える数字、`1E5`、`1.10`、`(100)`、`+81`、`10:30` を、作者の Excel で開いて確かめたものです。
- 人が Excel で開くのか、別のシステムに取り込ませるのかを先に決めます。両方なら2つ作るか聞き、分からないときは値をそのまま書いて、Excel で開くと変わる列があれば返事に書きます。
- 列ごとに全部の行の値を見て、表の形に1つでも当たる列は、列全体を `="1-2"` の形で書きます。
- 文字コードは BOM 付きの UTF-8 にします（Shift_JIS を求められたときはそれに従います）。
- Windows で Excel があれば実際に開いて全部の行の表示を読み、無ければ値を表と突き合わせ、Excel で確かめていないと返事に書きます。
- すでに Excel で上書き保存して変わったファイルからは戻さず、元のデータから作り直します。
