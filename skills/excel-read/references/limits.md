# できないこと

SKILL.md の「できないこと」の一覧。


## 一覧

- 式を計算し直すこと。保存された計算の結果だけを読む。Excel 以外の道具が式だけを書いて保存したファイルは、値が空のことがある（`dump` で `f` があって `v` が `null`。`table` では空のセルとして出て気づきにくい）。式の列に値が無ければ、Excel で開いて保存し直してもらうようユーザーに頼む。
- 表示の文字そのもの。表示形式の書式（`nf`）は出すが、それを当てた文字（`1,234千円`）は作らない。日付は日付の文字にする（`m"月"d"日"` の表示でも年まで出す）。小数は丸めずに出す（`0.30000000000000004` のように見えることがある）。
- 文字の色・塗りつぶし・取り消し線。色で意味を付けた表（赤は取り消し、など）は区別できないので、それらしい表ならユーザーに聞く。
- 図形とテキストボックスの中の文字、グラフ、画像、コメント、ピボットテーブルの定義。
- 数を文字として入れたセル（`'0123` など）は文字のまま出る。数のセルとは別に扱う。
- 隠した行と列・フィルター・表示形式は .xlsx・.xlsm だけで読める。結合セルは .xlsx・.xlsm・.xls だけで読める（.xlsb・.ods では `table` が埋めずに出し、標準エラーで知らせる）。
- Excel 4.0 のマクロ（シートに書かれたもの）、ボタンに割り当てたマクロの情報、パスワードで保護した VBA のコード。
- パスワード付きのファイル。
