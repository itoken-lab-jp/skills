# 表に整える（table）の細部

SKILL.md の「進め方」の手順4の細部と、設定ファイルの書き方。

## 手順4の細部

- 1つのシートに表が複数ある（縦に並ぶ、決算書のように左右に並ぶ）ときは、表ごとに範囲を変えて `table` を呼ぶ（帳票なら表ごとに設定ファイル）。どこからどこまでが1つの表かは自動では決めないので、`grid` を見て決める。同じ形のシートが並ぶ（月ごとのシートなど）なら、同じ設定ファイルで `--sheet` だけを替えて回し、シートごとに標準エラーと行数を見る（終わりの行を固定した設定は、行の増えたシートで黙って切れる。終わりは `stop_when` で決める）。
- 見出しは、結合を埋めたうえで、列ごとに上から空でない文字を `/` でつなぐ（SKILL.md の手順2の例の C 列は `売上/計画`。縦の結合で上下が同じ文字なら1つにする（`部門`））。セルの中の改行は除く。見出しが空の列は列の文字（`G`）、同じ名前は2つ目から `_2` を付ける（ほかの見出しとぶつかれば `_3` へ進める）。「選択範囲内で中央」で見せている見出しは、結合ではないので左の1列にしか付かない。崩れたら `columns` で名前を付ける。
- 見出しの行に数のセル（2行目に入った合計など）があると、それも名前につながり、標準エラーで知らせる。`header_rows` を見直すか、`columns` で名前を付ける。
- データの部分の結合は、既定（`--fill-merged all`）で覆われた全部のセルに左上の値を入れる。**金額や数量のセルが結合されていると、埋めた分だけ同じ数が重なり**、標準エラーで知らせる。そのときは `--fill-merged text`（文字だけ埋め、数は左上の行にだけ残す）で出し直す。`none` は何も埋めない。2行で1件の表（1件を2行に分けて書き、結合で束ねたもの）は1件1行にまとめられないので、どう扱うかをユーザーに確認する。
- 隠した行（フィルターで隠れた行も）は既定で出し、標準エラーで行数を知らせる。見えている行だけが目的なら `--visible-only`。どちらが目的か分からなければユーザーに聞く。隠した列は出したまま知らせる。
- 雛形の行（通し番号だけがあり、ほかは空の式）が続く表は、空でない列があるので捨てられない。品名などの必ず入る列で `stop_when` の `empty` を使って止めるか、`drop_rows` の `empty` で捨てる。
- 印刷のために見出しを繰り返している表は、繰り返しの見出しの行を `drop_rows`（見出しの文字と `equals`）で捨てる。
- 既定は CSV（区切りは `,`、`,`・`"`・改行を含む値は `"` で囲む。空のセルは空）。`--bom` で先頭に BOM を付ける（ユーザーが Excel で開く CSV のとき）。`--format json`（配列。空は `null`）・`jsonl`（1行1件）も出せる。

## 設定ファイル（table）

名前は自由（`帳票.table.json` のようにすると分かりやすい）。中の相対パスは無い。例は「2行の見出しの明細を、小計の行を捨てて、合計の行の手前まで出す」。

```json
{
  "sheet": "月次報告",
  "range": "A4:F",
  "header_rows": 2,
  "drop_rows": [{ "column": "B", "equals": "小計" }],
  "stop_when": { "column": "A", "starts_with": "合計" },
  "note": "部門別の明細だけを出す"
}
```

- `range`：見出しの最初の行から始める。終わりの行は書かずに（`A4:F`）`stop_when` で止める。終わりが決まっていて、同じ設定を別のシートやファイルに使わないときだけ書く（`A4:F12`）。
- `header_rows`：見出しの行の数（既定 1）。範囲の先頭からこの数の行を見出しにし、残りをデータにする。`header_join`：つなぎの文字（既定 `/`）。`columns`：列の名前を自分で付けるときの配列（範囲の列の数と同じ個数。例 `["部門","担当","計画","実績","差額","備考"]`）。付けても、見出しの行は `header_rows` の数だけ読み飛ばす。
- `drop_rows`：捨てる行。`stop_when`：その行の手前で終える。データの行にだけ効く。どちらも `{"column": "B", 条件}` か、その配列（配列はどれか1つに当てはまれば効く）。`column` は Excel の列の文字で、範囲の中の列（外なら終了コード 1）。判定は結合を埋めたあとの値で行い、セルと条件の文字の両方から空白（全角の空白も）を全部除いて比較する（`小　計` も `小計` に当たる。全角と半角の英数字、大文字と小文字は区別する。数のセルは `20` のような文字として比較し、表示形式は効かない）。
- 条件は `"contains": "文字"`・`"equals": "文字"`・`"starts_with": "文字"`・`"empty": true` のどれか1つ（2つ書くと終了コード 1）。
- `fill_merged`：データの結合の埋め方 `"all"`（既定）・`"text"`・`"none"`（`true` は `all`、`false` は `none`。引数 `--fill-merged`）。見出しはいつも埋める。`skip_hidden_rows`（既定 false。引数 `--visible-only` で true）。`skip_empty_rows`（既定 true。全部が空の行を捨てる。引数 `--keep-empty-rows` で false）。`format`（`csv`・`json`・`jsonl`）。`note`（メモ。道具は読まない）。
- `table`：Excel のテーブルの名前（引数 `--table`）。書いたときは `sheet`・`range`・`header_rows` を書かない（テーブルから取る）。列の名前はテーブルの見出しになる。
- 知らないキーがあると、打ち間違いとして終了コード 1 で止まる。引数（`--sheet`・`--range`・`--header-rows`・`--format`・`--fill-merged`）は設定より優先する。
