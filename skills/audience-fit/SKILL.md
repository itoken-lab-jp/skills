# 渡す前に、受け取る人の側から一度確かめる

作った物は、渡した先で使われる。資料に書いてある条件は見落としにくいが、受け取る人の持ち時間、知っている言葉、読んだあとの動きは資料に書いていないので、頭の中で動かしてみないと抜ける。作っている物に足していく項目は、一つひとつは正しく見えるので、書いているあいだは止まらない。だから、書き終えてから一度だけ、次の 1〜4 を確かめる。確かめたこと自体は、頼んだ人への返事に書かない。

## 1. 頼みと並べて削る

頼みの文を読み直し、頼まれた物を数える（「前年比を教えて」なら数字2つ、「返信を書いて」なら返信1通）。頼みの文と作った物を並べ、作った物の節・箇条・表を1つずつ見て、頼まれた物そのものか、それが無いと相手が次に動けない物かを問い、どちらでもなければ消す。大きさの目安は次のとおり。

- 数字や事実を聞かれた：答えと一言。3文まで。
- 判断や案を聞かれた：結論1文、理由3つまで、次にやること3つまで。全部で400〜600字を上限の目安にする。「一言で」「ざっと」と言われたら、もっと短く、最初の2〜3文で答えが済む形にする。
- 文書・メール・コードなどの成果物を頼まれた：成果物のほかに添える説明は3文まで。成果物の中身の大きさは、それを読む人・使う場で決める（下の項目）。
- 時間や紙の決まった場で使う物（打ち合わせ、発表、聞き取り、口頭の報告、「1枚で」）：1項目に何分・何行かかるかを見積もり、枠（30分、1枚）を割って入る数を出し、その数まで削る（1問に3分かかるなら、30分の聞き取りは10問まで）。

削った物は「補足」として付け直さない。まだ出せる物があれば、相手が次に欲しがりそうな物を1つだけ選び、最後に1文で「〜も出せます」と書く。

削らない物もある。危ないこと、相手が決めないと進まないこと、送る前に頼んだ人が確かめることは、上の数に入れずに最初に書く。「詳しく」「省かずに」「全部」と頼まれた物、記録・監査・引き継ぎのように後から事実をたどるための物は、日時・人・件数・金額を落とさない。その場合に短くするのは、成果物の外に添える説明だけ。

## 2. 元の資料から写した言葉を、読む人が知っているかで分ける

元の資料や頼んだ人の言葉（専門語・社内の呼び名・略語・型番）は、写しているあいだは引っかからない。写した名詞を拾い、1語ずつ「読む人は、これを読む日より前に、この言葉に出会っているか」を問う。出会っていない言葉は、次のどれかにする。

- 読む人が覚える必要の無い言葉：ふだんの言葉に言い換える。
- 読む人がこれから目や耳にする言葉（画面のボタンの名前、現場での呼び名）：言葉は残し、使った所に「何のことか、どこにあるか」を一言添える。説明を末尾の用語集に集めない（読む人は、その言葉に出会った所で止まる）。
- 読む人も知っている言葉：そのまま使う。知っている相手に説明を足さない。

読む人が知っているかが分からない言葉は、一言添える側に倒す（添えた一言は読み飛ばせるが、分からない言葉は読む人を止める）。

## 3. 社外や別の部署の相手に出す文は、相手の席で読む

頼んだ人の代わりに書いた文（依頼、交渉、返信、お知らせ）は、送る相手になって読み、読んだ相手が何を知り、どう動くかを考える。

- 頼んだ人の立場を弱くする事実（ほかに手が無い、期限に追われている、上限の額）や、相手に要らない内輪の事情（担当者の名前、社内の経緯）を、丁寧さや正直さのつもりで書いていないか。これらは書かなくても嘘にはならない。一方、相手に起きたこと（何が起きて、相手に何の影響があったか）は、隠さずに相手に分かる言葉で書く。
- 社内でまだ決まっていないことを、相手が当てにする形で書いていないか。使いたいなら、送る前に頼んだ人が確かめることとして、下書きの外（頼んだ人への返事）に書く。

## 4. 自分が書いた方針を、中身が守っているかを照らす

「〜は聞かない」「〜を先に」と方針を書いたら、中身を上から読み、反する項目が紛れていないかを見る。頼みの言葉にそのまま応えようとして入れた項目が紛れやすい（「払うかを確かめたい」と頼まれて、仮定の質問は当てにしないと書いたのに、「払う価値はありますか」と相手に尋ねる）。言い方を変えただけの同じ物も反する物に数える。反する物は、但し書きを付けて残さず、外す。外した項目の答えを、あとの判断（進めるかやめるかを決める目安など）の材料に数えるのもやめる。

## 自分で確かめることの限り

書いた本人には、自分の言葉が通じるように見える。2 は、写した言葉を拾うことで見落としを減らすが、全部は拾えない。多くの人に公開する文章や、読み違いの損が大きい文書は、事情を知らない別の読み手（文脈を渡していない別のエージェントか、読む人に近い人）に読ませて確かめる。自分で立てられなければ、頼んだ人に1文でそう勧める。

## 例

頼まれた言葉：「新しく入るアルバイトの人が初日に一人で開店準備ができるように、店長の話のメモを1枚にまとめて」

外す形：メモの話を全部拾って60行にし、月初や棚卸しの日だけの作業も並べ、「ドロアに釣り銭を入れる」とメモの言葉のまま書く。返事には、構成の説明と省いた物の一覧を付ける。

渡す形：毎日やることだけを時刻の順に30行ほどに並べ（1：1枚に入る行数まで削る）、止まると困る所（警備の解除は30秒以内、釣り銭が合わなければ開店せず店長に電話）を目立たせる。「レジの引き出し（ドロア）」のように、初めての人が知らない言葉には一言添える（2）。画面のボタンの名前は残し、「『開設』（レジの画面の左上のボタン。押すとその日の営業が始まる）」のように、何のことか・どこにあるかを添える（2）。返事は成果物の外の説明なので3文まで（1）：「毎日やることに絞りました。月初や棚卸しの日の作業も、要れば別の1枚で出せます」。
