# 色と箱の役割を決める

色と箱は、1つずつなら自然に見えても、ページをまたぐと意味がばらける（区切りの線があるページでは灰色、別のページでは主の色。課題の色を、別のページでは呼びかけに使う）。1枚目を作る前に役割の表を書き、作り終えたら全ページを表と照合する。表に無い使い方が出てきたら、表に行を追加するか、その使い方をやめる。

## 設計表のひな形

スライドを作る前に、次を作るスクリプトの先頭か1つのファイルに書く。作ったあとの照合は、この表と一覧の画像を並べて行う。

```
# 設計表
持ち帰ってほしい1文：
テンプレート：見出しの欄（位置・高さ）／本文の欄／まとめの欄（下にあれば見出しの下へ移した）
文字の段（見られ方で選んだ値）：見出し ／一文 ／本文 ／添え書き ／注記

## 色の役割（下の例を、このテンプレートの色で書き直す）
| 色 | 役割 | 上限 |

## 芯の図
何の絵か：
育てるページと変える所：p3 で全体 → p4 で○○に色 → p6 で消える所を灰色の点線

## ページ
| p | 見出し | 主張（見出しか下の一文の1か所） | 図の型 | 濃い面 | 差し色 |
```

## 色の役割（例）

主の色と差し色はテンプレートの色を使う。無ければ題材から選ぶ。

| 色 | 役割 | 上限 |
|---|---|---|
| 主の色の濃い面（白い文字） | そのページで一番見てほしい所（結論、目指す状態） | 1枚に1か所 |
| 主の色のうすい面 | 図の部品（物、手順、役割） | |
| 主の色の矢印 | これからの流れ、つながった状態 | |
| 灰色の矢印 | 今の流れ、手作業の流れ | |
| 灰色の面 | 比較の基準、過去のもの | |
| 差し色のうすい面 | 役割を1つに決める（この例では、課題と手間のかかる所） | 1枚に1か所 |
| 灰色の点線の枠 | 失われるもの、無くなるもの | |
| 灰色の細い線 | 区切り | |
| 主の色の文字 | 番号とラベルだけ | |
| 黒と灰色の文字 | 本文と補足 | |

- 1つの色に2つの役割を持たせない。「見てほしい所」は主の色の濃い面が受け持つので、差し色は別の役割1つに決める（「課題」に決めたら、呼びかけや残った値の強調には使わない）。
- 濃い面と差し色の面は役割が違うので、1枚にそれぞれ1か所まで置ける。どちらも無いページがあってよい。
- 同じ役割のものは、どのページでも同じ色にする。区切りの線、矢印、番号で食い違いやすい。
- 色を付ける理由を言えない所は、灰色か黒にする。

## 箱と枠

| 対象 | 規則 |
|---|---|
| 塗りの箱 | 図の部品（物、手順、状態）だけに使う |
| ページ全体の根拠、条件、留保 | 箱に入れず、余白か細い線で区切って図の下に置く |
| 部品の説明（中身、値の添え書き） | その部品の中か、すぐ横に置く |
| 箱の枠線 | 付けない（塗りだけで区切る）。点線の枠（失われるもの）だけ例外。流れやつながりは、箱と矢印で示す |
| 横に並ぶ箱 | 同じ大きさ。中身は上ぞろえ（行数が違っても題の高さがそろう） |
| 箱の入れ子 | 1段まで。色の面の上に載せる部品は白い箱 |
| 主張の1文 | 見出しの欄が細い1行で主張を言えないとき、見出しの下に箱なしで置く。まとめの欄が下にあるテンプレートは、作る前にレイアウト（スライドマスター）の欄を見出しの下へ移す。会社の共有テンプレートは直さず、写しを直す |

- 全部を箱に入れると、どれも同じ重さに見え、図の部品と説明の区別が消える。箱を外しても意味が変わらない所は、外す。
- 余白が大きく残るページは、箱を大きくして埋めない。図を大きくするか、根拠の文を追加する。

- 主張の1文を上に置くのは、主張を読んでから図を見られるため。下の塗った帯は、どのページでも一番目立ち、図の中の強調と競う。
- 主張の欄がレイアウトで下に作ってあると、「上に置く」と指示しても作り手はその欄に書く（同じ原稿で4本中1本しか移さなかった）。レイアウトの欄を先に動かすと、2本とも上に置いた。

## そろえる数の例

- 角丸の半径は2段（例：箱 12pt、札 6pt）。PowerPoint の角丸は短い辺に対する割合なので、大きさごとに計算して入れる。
- 余白は 8 の倍数（箱の間 16pt、箱の内側 8〜16pt）。行間と段落の間はテンプレートの値。

## 照合のしかた

一覧の画像を開き、色ごとに全ページを通して見る（濃い面だけ、差し色だけ、矢印だけ、線だけ）。1ページずつ見ると、ページの間の食い違いに気付けない。
