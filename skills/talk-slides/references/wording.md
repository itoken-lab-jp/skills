# スライドの言葉

原稿は耳で聞く文、スライドは目で拾う文。原稿の文をそのまま写すと、過去形の物語文（「〜した」「〜だった」）と和語の動詞が画面に並び、資料らしく見えない。場所ごとに形を決める。

| 場所 | 形 | 例 |
|---|---|---|
| 見出し | 欄に2行入るなら主張を、名詞句か「〜を＋サ変名詞」で止める。細い1行の欄なら何の話かの名前 | 「手順書を開いた人は 29% から 71% に増加」「校正の手順を飛ばしたまま 4,200 個を出荷」 |
| 見出しの下の一文 | 述語まで書く文。1〜2 行。常体か、です・ますかを1本でそろえる | 「読まれない原因は、読む人ではなく手順書の形にある。」 |
| 図の下の根拠・条件・留保 | 述語まで書く短い文。条件と留保の述語を落とさない | 「派遣と休職中の人を除いた数。」 |
| 箱・箇条・図の横の文 | 体言止めにそろえる。句点は付けない | 「現場の3人に聞いて質問を再選定」「担当者と期日を決定」 |
| ラベル | 2〜6 字の漢語 | 「調査の結果」「変更点」「実施時期」 |
| 大きな数字の添え書き | 何の数字かを名詞句で | 「全数の再測定にかかった延べ人数」 |
| 問い・結びのページ | 話す言葉のままの文でよい | 「最後に手順書を開いたのは、いつですか。」 |

## 体言止めで意味を落とさない

体言止めは短いが、時（済んだ・これから）と確かさが消えやすい。次で残す。

- **「を」を残す**：「コスト削減」は、した・する・すべきのどれか分からない。「コストを 12% 削減」と書けば動作だと分かる。
- **時と確かさは名詞で添える**：済んだことは「実施済み」「達成」「実績」、これからは「予定」「見通し」「方針」、確かでないことは「想定」「見込み」「可能性あり」。年月を添える（「6月から実施」）。
- **見出しが話題の名前のときは、主張の1文を見出しの下に述語まで書く**。ここまで体言止めにすると、何を言いたいページかが消える。
- **1つの箱・1つの箇条の中で、体言止めと動詞止めを混ぜない**。そろえにくい動詞は、類義の漢語にするか（話す→説明、決める→決定、見比べる→照合）、語順を入れ替える（「担当が足りている」→「十分な担当」）。

## 画面に出さないもの

- 過去形の物語文（「〜を調べた」「〜と分かった」）：「調査の結果」「判明した点」のように名詞にするか、ノートに回す。
- 接続詞と呼びかけ（「そこで」「しかし」「みなさん」）：原稿で言う。関係は配置と記号（→、／、①②③、※）で示す。
- 「〜ではなく、〜だった」の対比：主張の1文に1回まで。見出しと箱の両方で繰り返さない。
- 現場の作業や物の名前は言い換えない（現場の呼び方が正）。同じ意味の語は1本の中で1つにそろえる。

出どころ：公開されている上場企業の説明資料 24 枚の観察（箱・箇条の約 85% が体言止め、見出し 12 枚中 10 枚が名詞句かサ変名詞止め）と、箇条書きの体言止めについての2つの立場（そろえて使う／曖昧になるので避ける）。sources.md の「論文でない出どころ」。
