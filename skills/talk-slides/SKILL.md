# 話す発表のスライドと原稿を作る

発表を依頼されて、メモや資料の順のまま作ると、次の所で外す。

- 聞き手が「自分の話だ」と思える所が最後に来る。原稿が持ち時間の半分しかない。部署の言葉を説明なしに出す。一部の人への依頼を全員に言う。
- 話すことを全部画面に書くか、削りすぎてスライドだけでは何の主張か分からない。
- 1枚ずつ作るので、ページをまたぐと色の意味・図・主張の置き場がばらける。テンプレートの欄や原稿の言い回しが、ここの規則より強く出る。

だから順を決めておく。**原稿 → 設計表 → スライド → 全ページを並べて照合して直す。** 1枚目を作る前に全ページの設計を書き、作ったあとは1枚ずつでなく全体で見る。

## 1. スライドがどう見られるかを決める

**既定は「話すときに映し、あとで資料だけでも読まれる」。** 出なかった人がスライドだけを読むので、スライドだけで主張と根拠が分かる量を書く。文字を大きく少なくすることを目的にしない。

- **既定**：形式の指定が無ければ PowerPoint（.pptx、16:9）で作る。1枚に、主張、図か表、根拠・条件・留保の文。画面の文字は1枚 200〜300 字。16:9（幅 960pt）で、見出し 24〜26pt、見出しの下の一文 20pt、本文 16pt（箱の題は 18pt まで）、添え書き 14pt、注記と出典 12pt。本文を 14pt に下げるのは、根拠の文が 16pt で入らないページだけ。大きさが違うスライドは同じ比で変える。図の文字の下限を 18pt 以上で定めた手順や検査がほかにあっても、発表のスライドではこちらが先（12pt 未満だけ修正）。
- **大きな会場で映すだけ**（依頼にそう書いてあるとき）：1枚 100 字まで、本文 24pt 以上。読ませる版は別に作る。
- **配って読ませるだけ**：理由と条件をさらに文で書く。本文 12〜14pt、1枚 250〜400 字、見出し 20〜24pt。出典と脚注は 8pt まで。結論と決めてほしいことを最初の1枚に置き、比較するものは表にする。ノートに説明を回さない。2 の時間、3 の入口の順と原稿、7 の 2 と返事の字数は使わない。

## 2. 目的・聞き手・時間を決める

- **持ち帰ってほしいことを1つ、1文にする**（「毎日の点検の記録が、来年の設備の更新の順番を決めている。だから『異常なし』をまとめて付けない」）。行動か問いの形にする。
- **聞き手を2〜3行で書く**：誰で、毎日何をしていて、何を知らないか。
- **持ち時間から量を決め、書いたあとに数える。** 原稿は 1 分あたり 250〜300 字（10 分なら 2,500〜3,000 字）。枚数は1枚に1〜2分。スライドの印の行を除いた話す部分の字数を、文字単位で数える（`wc -m` はロケールによってバイトを数える）。足りなければ元の資料にある実例や聞き手の心配への答えを追加し（資料に無い事例や数字は作らず、【】で聞く）、多ければ節を削る。
- 依頼した人の考えがまとまっていないときは、目的の1文を返して確認する。「組み立ては任せる」なら決めて作り、決めた1文を返事に書く。

## 3. 話の順を組み、原稿を書く

- **聞き手の入口を前半に置く。** 聞き手の毎日の仕事とこの話のつながりを、最初の2〜3枚で言う。型は「聞き手のいま → うまくいっていない所 → 問い → 答え → 頼み」。書き手の経緯から始めない。
- **始めの問いか主張に、最後に同じ言葉で戻る。**
- 聞き手の知らない言葉は言い換えるか最初に一言説明し、筋に要らない仕組みの話は省く。
- **依頼は宛先を言う**（「班長のみなさんへ」）。聞き手が気にすること（「手間が増えるのか」）への一言を入れる。聞き手の仕事を責める言い方は、仕組みの話に言い換える。
- **事実は元の資料のまま。** 数字を丸めすぎず計算し直さず、見込みと推測はそうと分かる言い方のまま残す。確認できない日付や名前は【】で残す。
- 実例は、言いたいこと1つにつき1つ。
- **原稿が先。** 話し言葉で1文を短く書き、切れ目ごとに1枚、1枚に言うことは1つ。原稿に `（スライド 3：点検の記録の 4 割を、週末にまとめて記入）` のように番号と見出しの印を入れ、同じ文をノートにも入れる。ページを変えたら印とノートを合わせ直す。「原稿は要らない」と言われたら書かず、話す要点をノートに数行置く。
- 10 分を超える発表や、聞き手が書き手と違う部署のときは、節ごとの1文と時間の骨子を、経緯を知らない読み手に聞き手の立場を渡して読ませ、止まった所を修正する。

## 4. スライドを作る前に、設計表を書く

スライドを作るスクリプトの先頭か別のファイルに書き、作る間はそれを見る。**references/color-and-boxes.md をここで開き、そのひな形を埋める。**

1. **テンプレートの欄を見る。** 新しく作るときだけ。既存のスライドの修正では欄を動かさない。レイアウトの見出し・本文・まとめの欄の位置を読む。見出しのすぐ下に箱なしで一文（主張か、その理由・条件）を置くので、まとめの欄が下にあるなら、作る前に写しのレイアウトでその欄を見出しの下へ移す（「上に書く」と決めても、欄が下にあると作り手は欄に書く）。会社の共有テンプレートは直さない。テンプレートが無ければ、色（主の色1つ・差し色1つ・灰色）、文字の段、骨組み（章の名前・見出し・ページ番号の位置）を決める。色の指定が無いときは題材から選び、毎回同じ紺にしない。
2. **色の役割表**：面・矢印・線・文字の色ごとに役割を1つ。濃い面は「一番見てほしい所」で1枚に1か所、差し色は役割1つ（課題など）で1枚に1か所。
3. **芯の図を1つ決める**（物が流れる道筋、前と後、全体のうちのどれだけ）。どのページでそれを育てるか（部品を足す、1か所に色、消える所を灰色の点線）を書く。何も変わらない繰り返しのページは置かない。
4. **ページの表**：番号、章の名前（見出しの上に小さく）、見出し、主張の1文、図の型、濃い面の1か所、差し色を使うか。見出しの欄に2行入るなら見出しを主張の名詞句にし、下の一文は理由か条件にする。欄が細い1行なら見出しは何の話かの名前にし、主張は下の一文に書く。どちらでも主張を2か所に書かない。図の型は中身の形から選び（流れ、前と後、割合、2軸、年表、入れ子）、全ページ同じ並べ方（カード3枚）にしない。
5. **文の形**：スライドの文は文書の言葉にする。見出しは名詞句か「〜を＋サ変名詞」、箱と箇条は体言止め、述語まで書くのは、見出しの下の一文と、図の下の根拠・条件・留保の文だけ（条件と留保は述語を落とすと意味が変わる）。語は仕事の文書の漢語（確認、修正、担当者）。原稿の「直す人と日を決めました」は「修正の担当者と期日を決定」。現場の作業の名前は現場の呼び方のまま。同じ意味の語は1つにそろえる。**references/wording.md を開いてから**ページの表の文を書く。

## 5. 1枚の作り

- **スライドだけを読んだ人が、原稿を聞いた人と同じ結論と根拠にたどり着けるか**で量を決める。主張を支える数字・条件・例外は画面に載せる。図と数字だけで説明が無いページは少なすぎる。
- **話す文を写さない。** 画面は体言止めや短文の要約（そっくり同じ文は理解を落とす。references/sources.md の 3）。つなぎ、呼びかけ、エピソードの細部はノートへ。
- **図を大きく置く。** 見出しと一文は上の約2割、図の領域は面積の 6〜7 割で横幅いっぱい。部品の説明はその部品の中かすぐ横、ページ全体の根拠は箱に入れず図の下に文で。空いた所は図を広げるか根拠の文で埋め、文字を大きくして埋めない。
- **塗りの箱は図の部品（物・手順・状態）だけ。** 説明の文は箱に入れない。横に並ぶ箱は同じ大きさで上ぞろえ。1枚に図は1つ。話す順が大事な図は ①②③ を話す順に置く。
- 数量の棒や折れ線は PowerPoint のグラフで入れる（言いたい系列だけ主の色、ほかは灰色）。言いたい数字は本文の3〜4倍、単位はその 1/3。「212 のうち 14」は粒を並べて該当だけ色を付ける。
- 表紙・章の変わり目・結びは主の色を全面に敷く。これらと問い・山場は、文1〜2行か1点だけを大きく見せるページにする。問いのページに答えを見せない。
- 地は白かうすい灰色、基本の箱は主の色のうすい側。角丸の半径は2段、余白は 8 の倍数にそろえる。比較の基準・過去は灰色、無くなるものは灰色の点線の枠。明るい色の上に白い文字を載せない。架空の数字の図には「イメージ（数字は架空）」。
- 単語だけの見出し（「背景」）にしない。
- 文字の多いスライドを修正するときは、消さずに要約するかノートへ移し、どこに移したかを返事で言う。元のテーマとレイアウトのまま直す。

## 6. 全ページを並べて照合し、まとめて直す

1枚ずつ見て「よい」と判断しない。全ページの一覧の画像を作って開き、設計表と次を数える。

1. **色ごとに全ページを通して見る**（濃い面だけ、差し色だけ、矢印だけ、線だけ）。濃い面か差し色が2か所あるページ、表に無い色の使い方を書き出す。
2. **芯の図**が、育てるページで同じ位置と大きさか。
3. **主張**が各ページ1か所（見出しか、その下の一文）か。下の帯や箱に二重に書いていないか。
4. **空き**：図と文の下に、高さの1割を超える空白が残るページ。
5. **文の形**：スライドの文字を全部書き出し、「〜した」「〜ます」「〜です」で終わる箱と箇条、和語の言い方（直す、確かめる、やり方）を数える。
6. **量**：スライドだけで主張と根拠が分かるか。文字が少なすぎるページ、話し言葉を写したページ、見出しと図を見て何のページか分からないページ。
7. 文字の重なり・はみ出し・語の途中の折り返し（測る道具が手元にあれば通す）。

書き出したものを全部直してから、もう一度一覧を作って見る。

## 7. 渡す前に確認する

1. 見出しと主張だけを1枚目から順に読み、話が通って 2 の1文に着くか。
2. 原稿の字数が持ち時間に合うか。原稿の印・ノートがスライドの番号と見出しに合うか。
3. 始めと終わりが同じ言葉か。依頼に宛先があるか。見込みと推測の留保が残っているか。
4. 返事は短く：保存した場所、決めた1文、原稿の字数と枚数、確認してほしい所（【】で残したもの、決めた前提）。

## 人と一緒に修正するとき

- 人が .pptx を手で修正し始めたら、その .pptx が正。丸ごと作り直さず、依頼された所だけを書き換える。PowerPoint で開いている間（`~$` で始まるファイルがある間）は書き換えず、閉じてもらう。
- 見え方は、人が実物を見た感想が正。早めに一覧の画像かファイルを渡す。

## 小さい依頼のとき

1枚か、1〜2分で話す数枚なら、聞き返さず、骨子も原稿も設計表も作らずに、主張の見出しで作り、画像で確認して渡す（話すメモが要りそうなら、ノートに数行）。
