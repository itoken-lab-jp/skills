# 市場の売買・賭けの決まりを読むとき

土台は、同じ時期の市場全体の動きと、売買の費用（値幅・手数料・控除率）と、買う時点の値段にもう入っている情報。市場全体を引いた残りから、費用を引いた分で読む。

- 選ぶのに使う値段が、買う時点で分かるものかを見る（最終の値段で選んでいないか）。
- 値段がもう取り込んでいる配られた列（ハンデ、騎手や担当の割り当てなど）は、モデルに入れたうえで、その列の効果としては読まない（外すと、値段との比べが崩れる）。
- モデルが土台に足した分は、結果を入れ替えた版と比べる。
- 入れ替えは、決まりを壊さない組の中で行い（同じレースの中、同じ日の中）、20 通りほどの最大を越えなければ、中の升や条件は読まない。
- 学ぶ期間の取り方（直近だけ・全部）を変えても結論が動かないかも見る。
