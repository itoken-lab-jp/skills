# 見立てを集める（データを掘る前に）

何が効くか見当がついていない探索で、データを並べて形を探す前に使う。でたらめに分けていない施策の効果を出す頼みでは、「自然の実験」と「対立する説」を使う。

- **仕組みから思いつく**：結果を動かしているもの（人・物・時刻・場所・決まり）を挙げ、それぞれ「なぜ結果を動かすはずか」を1文で言う。言えたものを候補にし、作業場所の台帳（例：`ideas.md`、1行1候補）に、確かめ方と使うデータを添えて並べる。会話の途中の思いつきも台帳に足す。台帳に並べただけでは、試した数に数えない。流すときに、その行を本文の 1 の形で書き、2 の一覧に入れて数える。
- **一次情報の持ち主を先に並べる**：その対象を誰が一番近くで見ているか（運営する側、現場で手を動かす人、毎日見て書く人、記録や判定をする人、受け手・客、公の機関）と、それぞれが何を知っていそうか、どこに書き残していそうかを並べてから、対象に近い順に当たる。同じくらい近ければ、書き残したものがある方から。作業場所にその人たちの書いたもの（お知らせ・日報・議事録）があれば、データより先に読む。聞いた話は、独立した2つの出どころで合うか、数字で裏が取れるまで見立てにとどめる。同じ元を写した記事がいくつあっても1つと数える（出どころの数は、よく調べた情報の代わりにならない）。言う人の利害（煙幕・宣伝・思い込み）も添える。
- **自然の実験を探す**：決まり・設備・道具・時間帯が変わった日を年表にする。変わった所と変わらなかった所を、同じ時期の前後で比べられるので、たくさん試して当たりを拾うより強い証拠になる。日付は一次の資料（運営の発表・公の資料・報道）で確かめ、同じ時期に重なった別の変更も書く。前後の比べも1つの試しなので、本文の 1 に書いてから流し、2 の数に入れる。変更の日が最後に1回だけ使う範囲に入るなら、その比べは探す段では流さず、最後の確かめとして線を先に書いて1回だけ使う。
- **対立する説を並べる**：1つの見立てごとに、同じ結果を出せる別の説（時期・季節が効いているだけ、強い人や良い条件が同じ所に集まっているだけ、記録のしかたが変わっただけ）を2つ以上書く。説ごとに「この説が正しければ見えるはずのもの」を流す前に書き、比べ方は、説の間で差がつくものを選ぶ。どの説にも合う証拠は集めても効かない。
