# 数字の表が無いとき（会話・メモ・事例・人の声から読む）

振り返りのメモから効いた施策をまとめる、お客さんの声から理由を読む、成功事例から共通点を抜き出す、という依頼も、同じ3つの取り違えで外す。検定の代わりに、材料に次を問う。答えが材料の中（別のメモ、添えられた集計）にあることが多いので、依頼されたファイルの周りも読む。

- **何もしなかったら、どうなっていたか**（土台）。「始めたあとに良くなった」は、例年の動きや、していない所の動きと比較する。「選んだ先が良い」は、選ぶ前から良かったかを見る。
- **その話は、うまくいかなかった側にも当たるか**（土台）。成功した所の共通点は、成功しなかった所もしていれば特徴ではない。不満の声は、不満のない側（続けている客）も同じことを言っていれば理由ではない。
- **何件の話か、誰の声が無いか**（振れ）。数件の成功、長く強い1件の声は、件数のまま扱う。答えた人・聞けた人が、全体のどの部分かを見る。
- **順番は逆でないか**（向き）。結果の良い所に手をかけていないか。

依頼された形（順位・トップ3・手引き）は出す。そのうえで、確かなもの、比較すると消えるもの、まだ分からないものを分け、分からないものには次の確認方法を1つ付ける。

## 文書を AI に読ませて材料にするとき

- 良し悪しを聞かず、書いてある数字と言葉だけを抜かせる（過去の文書に判断をさせると、AI がそのあとの結果を知っているおそれがある。判断は抜いた値から自分で作る）。1回に聞く観点は1つ。
- 機械的な読み（言葉の検索）と突き合わせて、読み落としを拾う。拾えた件数を期間・種類ごとに見てから範囲を広げる（言い方が種類で違う）。「前は書いてあったのに書かなくなったこと」も材料になる。
- 依頼の文を修正しながら当たりを探すと、試した数が増える。依頼の文も、流す前に書くものに入れる。
