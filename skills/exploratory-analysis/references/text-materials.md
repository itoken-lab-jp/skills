# 数字の表が無いとき（会話・メモ・事例・人の声から読む）

振り返りのメモから効いた施策をまとめる、お客さんの声から理由を読む、成功事例から共通点を抜き出す、という頼みも、同じ3つの取り違えで外す。検定の代わりに、材料に次を問う。答えが材料の中（別のメモ、添えられた集計）にあることが多いので、頼まれたファイルの周りも読む。

- **何もしなかったら、どうなっていたか**（土台）。「始めたあとに良くなった」は、例年の動きや、していない所の動きと比べる。「選んだ先が良い」は、選ぶ前から良かったかを見る。
- **その話は、うまくいかなかった側にも当たるか**（土台）。成功した所の共通点は、成功しなかった所もしていれば特徴ではない。不満の声は、不満のない側（続けている客）も同じことを言っていれば理由ではない。
- **何件の話か、誰の声が無いか**（振れ）。数件の成功、長く強い1件の声は、件数のまま扱う。答えた人・聞けた人が、全体のどの部分かを見る。
- **順番は逆でないか**（向き）。結果の良い所に手をかけていないか。

頼まれた形（順位・トップ3・手引き）は出す。そのうえで、確かなもの、比べると消えるもの、まだ分からないものを分け、分からないものには次の確かめ方を1つ付ける。
