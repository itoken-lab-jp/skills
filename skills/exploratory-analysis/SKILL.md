# 答えの見えない探索を迷走させない

答えがあるか分からない探索では、AI は一つひとつの計算は正しく、偶然の当たりを「見つかった」と言わないくらいの慎重さもある。外すのは進め方で、次の形が多い。

- 探す前に「何を満たせば効くと言うか」を決めず、結果を見てから線を引く。
- 最後に1回だけ使うはずの確かめのデータを、表に並べて覗く、「もう少し」と言われて2回目に使う。
- データの作り（時刻のずれ、欠け、記録のしかたの癖）を確かめないまま探し、作りの見かけを効果と読む。
- 試したスクリプトと結果を作業場所に残さず、何を何通り試したかを追えない。
- 外れたあと、次の手を「条件をさらに変える」で出す。なぜ効くはずかの見立てから出さない。

探すこと自体は楽観的に、数え方と結論は厳しくする。

## 頼みの形で、使う節を決める

- **探す頼み**（効く手・条件・決まりを探す、何通りも試す）：下の 0 から順に、全部を使う。
- **読む頼み**（起きたことの原因・要因・効果・順位を読む、決まった1つの手や決まりが効いたかを見る）：「数字を読むとき」と 4 と 7 を使う。でたらめに分けていない施策の効果なら、0 の自然の実験と対立する説も使う。切り口をいくつも試したら 2 で数える。確かめは時間の順で行う（前の期間で見つけた違いが、後ろの期間でも同じ向きか）。後ろの期間が小さくて線に届かないことを「無い」「偶然」と読まず、向きと大きさが前の期間と合うかと、どの大きさの差なら見分けられたかを書く。
- 読む材料が文章（振り返りのメモ・お客さんの声・成功事例）のときは、先に `references/text-materials.md` を読む。市場の売買や賭けの決まりのときは、先に `references/markets.md` を読む。
- **決まった表・集計・グラフを作るだけの頼み**：ここの手順を足さず、頼まれた物を渡す。数字に目立つおかしさがあれば、1行添える。

## 0. 見立てを集める（データを掘る前に）

何が効くか見当がついていない探索では、データを並べて形を探す前に、何がなぜ効くはずかの見立てを集める。でたらめに分けたテストの結果を見るだけの頼みでは、この節を飛ばして 1 から始める。でたらめに分けていない施策の効果を出す頼みでは、下の「自然の実験」と「対立する説」は使う。

- **仕組みから思いつく**：結果を動かしているもの（人・物・時刻・場所・決まり）を挙げ、それぞれ「なぜ結果を動かすはずか」を1文で言う。言えたものを候補にし、作業場所の台帳（例：`ideas.md`、1行1候補）に、確かめ方と使うデータを添えて並べる。会話の途中の思いつきも台帳に足す。台帳に並べただけでは、試した数に数えない。流すときに、その行を下の 1 の形で書き、2 の一覧に入れて数える。
- **一次情報の持ち主を先に並べる**：その対象を誰が一番近くで見ているか（運営する側、現場で手を動かす人、毎日見て書く人、記録や判定をする人、受け手・客、公の機関）と、それぞれが何を知っていそうか、どこに書き残していそうかを並べてから、対象に近い順に当たる。同じくらい近ければ、書き残したものがある方から。作業場所にその人たちの書いたもの（お知らせ・日報・議事録）があれば、データより先に読む。聞いた話は、独立した2つの出どころで合うか、数字で裏が取れるまで見立てにとどめる。同じ元を写した記事がいくつあっても1つと数える（出どころの数は、よく調べた情報の代わりにならない）。言う人の利害（煙幕・宣伝・思い込み）も添える。
- **自然の実験を探す**：決まり・設備・道具・時間帯が変わった日を年表にする。変わった所と変わらなかった所を、同じ時期の前後で比べられるので、たくさん試して当たりを拾うより強い証拠になる。日付は一次の資料（運営の発表・公の資料・報道）で確かめ、同じ時期に重なった別の変更も書く。前後の比べも1つの試しなので、下の 1 に書いてから流し、2 の数に入れる。変更の日が最後に1回だけ使う範囲に入るなら、その比べは探す段では流さず、最後の確かめとして線を先に書いて1回だけ使う。
- **対立する説を並べる**：1つの見立てごとに、同じ結果を出せる別の説（時期・季節が効いているだけ、強い人や良い条件が同じ所に集まっているだけ、記録のしかたが変わっただけ）を2つ以上書く。説ごとに「この説が正しければ見えるはずのもの」を流す前に書き、比べ方は、説の間で差がつくものを選ぶ。どの説にも合う証拠は集めても効かない。

## 1. 探す前に書く（1つの試しごとに）

作業場所のファイル（例：`hypotheses/001-<名前>.md`）に、流す前に書いて残す。版の管理があればコミットする。書いた時刻が「先に決めた」証拠になる。

- **見立て**：なぜ効くはずか。誰が・何が、なぜそう動くのか（例：「月末は経理の締めで支払いが集中するので、月末の数日は問い合わせが増える」）。見立てを言えない形を試すときは「探索」と書き、合否を付けない（下の 2 と 7）。
- **線**：何を満たせば「効く」と言うか。数字で書く（効果の大きさ、t の値、期間の前半と後半の両方でプラス、など）。費用（手数料・手間・値引きの原資）を引いた後で見る。
- **比べる相手**：何と比べて良いと言うか。何もしない版、でたらめに選んだ版、時期をずらした版のどれか。決まりを当てはめる所だけをでたらめにして、ほかの条件（回数・長さ）はそろえる。
- **データの範囲**：探す範囲・確かめる範囲・最後に1回だけ使う範囲に分ける。時間の流れがあるデータは時間で分ける（古い方で探し、新しい方で確かめる）。
- **動かす値**：調整する値は5つ以内にし、試す範囲も書く。書いていない値は試さない。

## 2. 試した数を数える

- 試した決まり・条件・値の組み合わせを、捨てたものも含めて全部数え、一覧（例：`trials.csv`、1行1試し）に残す。同じデータを見てから直した版も、それぞれ1つと数える。
- 線は試した数に合わせて厳しくする。試した数 N の中の一番を選ぶなら、たとえば片側 2.5% を N で割った水準の t を線にする（N = 1 なら 1.96、N = 20 なら 3.02、N = 100 なら 3.48）。または、でたらめの版で同じ N 通りを探し、その一番の分布の 95% 点を越えるかで見る。
- 結果を書くときは「何通り試した中の一番か」を必ず添える。
- 「探索」として流したもの（見立ての無い形と、下の 7 の「なぜ？」の確かめ）も、一覧に「探索」と印を付けて残す。N には入れないが、その代わり探索で見つけた形は結果として出さず、事後の芽として、まだ使っていないデータで確かめる新しい試しにしてから数える。条件をいじる試しを「探索」と呼んで N を増やさずに回すことはしない。

## 3. 確かめのデータを汚さない

- 最後に1回だけ使う範囲は、決まりを固めてから1回だけ流す。表に並べる、平均を覗く、グラフで見るのも「使った」に入る。探す段階の表や集計に、その範囲を入れない。
- 使ったあとに直したら、その範囲はもう確かめに使えない。新しい範囲（これから来るデータ、まだ取っていない期間、本番で小さく試す）で確かめる計画を、流す前に書く。
- 使ってしまったら隠さず書き、その範囲での結果は「確かめ」と呼ばない。

## 4. 良すぎる結果と外れの両方で、まずデータを疑う

探す前に一度、データの作りを確かめる。結果が出たあとも、良すぎる結果（t が 5 を超える、特定の時刻・曜日・1件に効果が集中する）と外れの両方で、決まりより先にデータを疑う。

- **時刻**：時刻帯（UTC か現地時間か）と、日の区切り。分かっている出来事（発表・締め・祝日）が、データのどの時刻に出ているかで時計を確かめる。時期によってずれていないかも見る。
- **欠けと重なり**：1日の件数、週や月の初めと終わり、長い穴、同じ行の重なり。
- **記録のしかたの癖**：何の値か（買い値か売り値か、税込か税抜か、集計の締めの時刻）、特定の時刻だけ値が飛ぶ・戻る所、値幅0の行。最後に1回だけ使う範囲を除いて、時刻ごと・曜日ごとに値の分布を一度並べると、作りの癖が見つかりやすい。
- 作りの見かけを疑ったら、別の記録（反対側の値、別の出どころ、記録した人への質問）で確かめる。確かめられないうちは、その形を効果と呼ばない。
- **費用**：手数料・手間・値引きの原資を、上の 1 で書いた置き方どおりに引いたか。引く前と後の両方を見る。
- 直して測り直した結果は参考にとどめ、試した数は戻さない。直し方は、結果を見ずに決まるものだけにする。

## 数字を読むとき（原因・効果・順位を読む頼みにも）

見えている数字には、土台（何もしなくても起きた動き）、効き（知りたいもの）、振れ（偶然）が重なっている。フォルダーに前の分析のメモがあれば先に読む。ただし、答えになる数字はメモから写さずデータで測り直し、食い違えば返事に書いてメモの行を直す。

- **全体から読む**：まず全体の動きを、土台を引いた形で1つの数字にする。「落ちた」「鈍った」と頼まれたら、その実感がデータと合うか（いつから、どれだけ）を先に見て、最近変わった分の要因と、前から続いて全体を押し下げている要因の両方を出す。
- **配られた数字を原因と読まない**：列ごとに、結果の前に決まるか、誰かが結果や見込みを見て割り当てていないかを、データの説明か、その列と前の時期の結果の関係で確かめる。見込みや結果に合わせて割り当てられた数字（人員・広告費・訪問・割引・在庫に多い）と、結果より後に決まる列は、結果との関係を効果として読まず、打ち手にも、予測やモデルの説明の列にも入れない。暦で決まっている日（毎月の特売日・祝日）や天気のように、結果を見ずに決まるものは、効果を読んでよい。読めない理由は1行で書く。
- **土台を引く**：時系列は前年同期比か、季節・曜日を除いた残りで読む。施策は、対象と対象でない所の、前後の差どうしの差で読む。率や平均は、構成が変わった分と、集まりの中で変わった分に分ける。予測の精度は、使うときと同じ先の長さで過去の時点から何度か測り、素朴な予測（去年の同じ時期）を越えた分で読む。モデルが土台に足した分は、結果を入れ替えた版と比べる（`references/markets.md`）。
- **切る前に1本確かめる**：切り口（地域・年代など）で分ける前に、そこに違いがあるかを1本で確かめる（率なら表全体の検定、効果の違いなら交互作用の検定、順位なら前半と後半で続くか）。違いがあると言えない切り口は、中の順位や一番を発見や要因にせず、「違いは見られなかった」と1行で書く。ただし、件数の多い集まりが振れの幅を大きく越えていれば、候補に残す。
- **そろえて比べる**：差が見えたら、重なっている切り口（地域と立地の型など）の片方をそろえて、もう片方を見る。そろえると消える差は、要因にも手にもしない。
- **大きさに割って全体に戻す**：挙げた要因の全部について、それぞれが全体の動きを何ポイント・いくら動かしたかを出す（集まりの中で変わった分＝その集まりの変化 × 全体に占める割合、構成が変わった分＝割合の変化 × その集まりの水準と全体の水準の差）。前から続いている要因も、最近の要因と同じ形で数字にする。両方を足した合計が、全体の動きにおおよそ戻るかを見る。戻らなければ、まだ見ていない要因がある。
- **順位は件数で寄せる**：率の順位には件数を並べ、件数だけで出る振れの幅（全体の率 p、件数 n なら、およそ ± 2√(p(1−p)/n)）を横に置く。上位と下位が件数の少ない所に偏っていたら振れを疑い、全体に寄せた率か区間の下限・上限で付け直す。件数の多い所にある、振れの幅を越えた違いが本物の候補になる（最低件数の足切りだけでは、件数の多い所の本物が上位に出てこない）。頼まれた素の順位は、件数と一緒にそのまま出し、行動の先は寄せた順位で勧める。

## 5. 外れたとき・2回続けて外したとき

1. **データと費用を疑う**（上の 4）。試した数が少ないなら、外れを「効かない」と読まない。どの大きさの差なら見分けられたかを書く。
2. **何が残ったかを書く**：費用を引く前の形、効いた期間・場所・向き、まだ試していないやり方。悪い数字もそのまま書く。
3. **楽観の読み直しを1回だけする**：同じ結果を「どこなら効くか」の目で読み直す。見つけた形は「事後の芽」と書き、その場で合否を付けない。進めるなら、新しい番号で、まだ使っていないデータで確かめる計画を書いてから。
4. **棚に置く**：戻る条件と次の一手を1つ添えて、一覧（例：`shelf.md`）に置く。

2回続けて外したら、次を流す前に止まって、分かったこと・試した数・まだ疑っていない前提（データの作り、費用の置き方、比べる相手）を書き出す。次の一手は、条件をさらに変える案ではなく、別の見立て（なぜ効くはずか）から出す。

次の一手は、1つにつき1行で書く：見立て（誰が・何が、なぜそう動くのか）・一番安い試し方・期待する大きさ・やめる線。例：「使わなくなった会員は価値を感じていないので、ログインが3か月続けて減った会員は解約しやすいはず。今あるデータの翌月の解約率で見る。差が5ポイント未満ならやめる」。列や条件の組み合わせを並べるだけの案にしない。

「無い」「閉じる」は、同じ見立ての仲間（言い換え・範囲の絞り込みは同じ仲間）を通算で3回外したときか、依頼者が決めたときだけ言う。それまでは「このやり方では残らなかった」と、やり方に向けて書く。

## 6. 押されたとき

- 「もう少し粘って」「何か1つくらいあるでしょ」には、線を下げない。粘るなら、新しい見立てで試しを足し、試した数に足して同じ線で見る。条件をいじり続けて、通ったものを出すことはしない。
- 依頼者が、確かめの済んでいないものでお金や本番を動かそうとしたら、何で確かめて何をまだ確かめていないかを数字で言い、小さく試す・期限と損の上限を決めるなどの案を出す。動かすか、いくら張るかは依頼者が決める。

## 7. 書き方

- 最初の文は「何が残ったか」と「次の一手」。原因や要因を頼まれたときは、何が全体を動かしているかを大きさの順に2〜3個。
- 原因や効果を読んだ返事には、見たが違いが無かった切り口を1行ずつと、このデータでは分からないこと（配られた数字の効果など）と確かめ方を1つ添える。分からないことがあっても、分かる範囲の数字は出し切る。
- 相手に渡す返事は相手の言葉で書く。試した数と線は1文で添え、帳簿の言葉（N、棚、事後の芽）を並べない。
- 数字はそのまま書く（効果、t、何通りの中の一番か、年ごとや前半・後半）。「有望」「確実」「有意な傾向」のような言葉で盛らない。
- 試したスクリプト、試しの一覧、結果は作業場所に残す（一時フォルダーに置かない）。依頼者が次の回に追えるように、どこに何があるかを報告に書く。
- 結果を書くたびに「なぜ？」を3つ書く（変な数字、外れた期間、予想と逆の向き）。安く確かめられるものは「探索」として流してよい（扱いは上の 2）。
