# グラフを作る

問いがはっきりした依頼（「どの店が伸びているか」「2つの拠点に違いがあるか」）なら、AI は合う形をふつうに選べる。外しやすいのは、依頼方法が形を決めてしまう場面で、次の形になる。

- 「グラフにして」とだけ依頼され、データを全部そのまま載せる。12本の折れ線が12色で重なり、何も読み取れない。データの中の話（伸びた店、落ちた店）は見つけないまま渡す。
- 「差が分かりやすいように」と依頼され、棒グラフの軸を途中から始めて差を大きく見せる。
- 「円グラフで」と形を指定され、その形では読み比べにくいことを言わずに渡す。
- 出来た画像を自分で見ない。見て重なりに気付いても、「重なっています」と書いて渡す。

## 進め方

1. **このグラフで言うことを1文で置く。** 描く前に「新宿店と博多店が伸び、梅田店と仙台店が落ちている」のように、見た人に持ち帰ってほしいことを1文にする。依頼に問いがあれば、その答えを書く。問いが無い依頼では、聞き返さずに先にデータを見て（伸びと落ち、群の間の差、外れた値、分布の形）、変化や差がいちばん大きいものを1つ選ぶ。聞くのは、列の意味が分からず、読み方しだいで言うことが変わるときだけ。その1文をグラフの題にし（題を指定されていれば、題は指定のままにし、1文を副題か注記に書く）、返事の最初にも書く。形は、指定が無ければ、この1文がいちばん読み取りやすいものを選ぶ。
2. **言うことに要るものだけを目立たせる。** 系列や項目が多いとき（色で見分けるのは7つくらいまで）は、全部を同じ強さで載せない。言うことに関わる系列だけに色を付けて残りを灰色で残す、増減や差を計算して並べ替えた棒にする、1枚の画像の中に項目ごとの小さなグラフを軸をそろえて並べる、のどれかにする。項目は消さずに載せ、強さで差を付ける（「全部を見せて」と依頼されていれば、なおさら消さない）。名前は凡例でなく、線や棒のそばに直接書く（凡例と図を目で往復させないため）。色とフォントは、指定があればそれを使う：貼る先の資料のテーマ、会社やリポジトリの配色、Power BI のテーマの JSON、Excel のブックのテーマを、描く前に探して読む。Excel・Power BI・スライドのグラフはテーマの色を参照して塗り、値を写さない。自分で色を選ぶのは、指定が無いときだけにする。指定どうしが食い違えば、貼る先の資料のテーマに合わせ、返事で伝えて聞く。
3. **小さい差を見せたいときは、軸を絞って点や折れ線で見せる。** 0 から描くと、4.19 と 4.29 の差は見えない。差を見せるのが目的なら、差が見える範囲に軸を絞る。絞るときは、点や折れ線を使う（位置で読むので、0 から始めなくてよい）。軸の範囲を目盛りで読めるようにし、差の大きさを数字（「+0.10 点」）で図に書く。値そのものの棒は、軸を途中から始めない（棒は長さで読まれるので、0.1 の差が何倍にも見え、資料で見た人が軸に気付けば、信用を落とすのは依頼した人になる）。「棒グラフで」と指定されたときは、基準（施策の前の平均など）との差を棒にする。0 が基準になるので、棒の長さがそのまま差になり、軸を切らずに差が見える。棒をほかの形に変えたときも、差の棒にしたときも、理由を1文で伝える。
4. **形を指定されたら、その形で作り、読みやすい形を添える。** 依頼した人には、その形を選ぶ事情があるかもしれない。依頼された形（円グラフ、左右に別の目盛りを取る2軸のグラフ）で作り、その形の弱い所は手当てする（区分名と値を直接書く、並べる図の間で区分の順と色をそろえる、言うことに関わる区分を強調する）。言うことがその形では読み比べにくいとき（円を2つ並べて区分ごとの差を見せる、など）は、読み比べやすい形（並べた棒、下の「迷いやすい形」）を2枚目として1枚だけ添え、「区分ごとの差はこちらが読みやすい」と1文で伝える。どちらを使うかは聞かずに、両方を渡す。
5. **出来た画像を開いて見てから渡す。** 保存した画像を自分で開き、次を見る。日本語が □ になっていないか（描く前に使える日本語のフォントを確認して指定する）。文字や数字が重なったり、はみ出したりしていないか。単位と期間が題か軸にあるか。題を隠しても、手順 1 で置いた1文が図の形から読み取れるか。崩れを見つけたら、修正して（文字の位置や大きさ、図の大きさを変える）もう一度開く。気付いた崩れを修正せずに「重なっています」と書いて渡さない。修正は2回までにし、それでも残る崩れは、何が残ったかを返事に書く。画像を開く手段が無い環境では、見ていないことを返事に書く。
6. **返事は短く。** 手順 1 の1文、それを支える数字を1〜2文、保存した場所。データを見て気付いた、図の読み方を変えること（まだ集計の途中らしい月、外れた値）があれば1文。作り方の説明、フォントの話、依頼されていない分析の箇条書きは書かない。

## 迷いやすい形

形を指定されていないときに選ぶ形。形を指定されたときは、手順 4 で添える2枚目に使う。

- 単位の違う2つの推移を比較する：左右に別の目盛りを取ると、目盛りの取り方で交わる所と傾きが変わる。最初の時点を 100 とした指数で1つの軸に重ねるか、横軸をそろえて上下2段にする。
- 2つの時点や群で構成を比較する：円を並べると、区分ごとの差を角度と面積で見比べることになる。同じ軸の上の棒で構成比を比較する。
- 群の間で値を比較する：平均の棒だけにせず、分布（ヒストグラム、箱ひげと点）を見る。平均が同じでも形が違うことがある。
- 2つの量の関係で、値が数十から数万のように何桁にも広がる：ふつうの目盛りでは大半の点が隅に固まるので、対数の軸にする。

## 言うことも形も明らかな依頼のとき

1つの系列の推移や、数個の項目の比較のように、言うことも形も明らかな依頼では、1枚作り、開いて見て、渡す。聞き返す、別の形を何枚も添える、分析を書き足す、は要らない。開いて見ることだけは省かない。
