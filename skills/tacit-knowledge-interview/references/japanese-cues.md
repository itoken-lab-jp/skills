# 日本語の言い回しの読み方

手順の 5（確かめる）で使う。日本語の会話では、本人はわざわざ断らず、言葉を弱めて伝えることが多い。字面のまま手順書に書くと、後任は違うことをする。下の言い方が出たら、意味を決めつけずに、確かめる問いを控えに積み、今の話が一段落したら戻る。確かめるまでは、メモに本人の言葉のまま書き、「（未確認）」を付ける。

| 本人の言い方 | よくある意味 | 確かめる問い（1つだけ） |
|---|---|---|
| 「普通にやるだけです」「特に何もしてないです」 | 本人には当たり前で、言葉にしたことがない | 「昨日の分で、すぐに片づかなかったものはありましたか」（具体の1回に変える） |
| 「大したことはしてないです」「誰でもできますよ」 | 謙遜。中身はある | 「新しい人が同じことをやると、どこでつまずきそうですか」 |
| 「毎日」「全部」「いつも」 | 原則で、忙しい日や例外では違うことがある | 「月末の忙しい日も、全部その日にやりますか」 |
| 「〜ようにはしてます」「できるだけ〜」 | 守れない時がある | 「できなかった時は、どうなりましたか」（手順書で「必ず」に強めない） |
| 「場合によりますね」「ケースバイケースです」 | 分かれ目の条件が頭の中にある | 「最近、いつもとやり方を変えた1件は、何が違いましたか」 |
| 「あとは……まあ、いいか」「いや、なんでもないです」「それは置いといて」 | 話しにくい・長くなる・本人が重要でないと思っている。取りこぼしやすい | 一段落してから「さっき言いかけた〇〇は、どんな話でしたか」 |
| 他人の「確認しておきます」「検討します」 | 返事が来ない・遅いことが多い。本人はその後の追いかけ方を持っている | 「返事が来ないときは、何日待ちますか」（そのあとの動きは次の発言で） |
| 「前向きに検討します」「善処します」（取引先や上司の返事として出たとき） | 断り、または当面やらないことが多い | 「それで、実際にはどうなりましたか」 |
| 「上に聞きます」「課長が見てます」 | 判断の線がある | 「いくら（どんな時）から上に聞きますか」 |
| 上司や相手の「いつでも連絡して」「遠慮なく言って」 | 実際には線がある（夜中は急ぎだけ、など）。字面のまま書くと後任が困る | 「実際に夜中（休みの日）に連絡したのは、どんな時でしたか」 |
| 「たぶん」「〜だと思います」「前からそうしてる」 | 根拠が本人の記憶か慣習。決まりの文書があるかは別 | 「それは決まりとしてどこかに書いてありますか、それとも慣習ですか」 |
| 「異動までにはやっておきます」「あとで送ります」（本人の約束） | 期限が無いと流れやすい | 「いつ頃までにもらえますか」（置き場所は次の発言で） |
| 短い答え・同じ答えの繰り返し | 問いが抽象的すぎる、または疲れている | 問いを具体の1回に変える。続くなら、残りの控えを絞り、早めに締める |

表に無い言い方でも、「言い切り」「弱め」「言いかけてやめる」「他人の約束」の4つの形に当てはめて読む。
